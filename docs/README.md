# Roku documentation

Reference material for the native BrightScript / SceneGraph Roku client that
plays user-supplied M3U playlists and local videos served by a media helper.

- [Architecture and repository decision](architecture.md) — the single native application and its two distribution formats.
- [Install the Roku developer preview](installation.md) — the sideload ZIP, what it contains and how it differs from a Beta app.
- [Local videos on Roku](local-videos.md) — folders shared by the read-only media helper and the models that can play them.
- [Release, signing and Beta distribution](release.md) — the reproducible host-side ZIP build and what it does not include.
- [Automatic merge for trusted pull requests](automerge.md) — who gets the `automerge` label and how to withdraw it on purpose.
