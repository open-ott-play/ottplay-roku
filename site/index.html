This page distributes the native Roku app. The here.now web player remains separate. You install the ZIP on Roku through Developer Mode; opening this website on a TV does not install it.

One package. Ready to sideload.

The first preview is prepared without a connected device. Compilation and automated host tests are checked; playback, focus and compatibility still need a real Roku test.

01 / PREPARE

Enable Developer Mode

Follow Roku’s setup guide. Record the device IP address and choose an installer password. Roku has one sideload slot: this app replaces the current development app.

02 / INSTALL

Upload the ZIP

Open the device’s Development Application Installer in a browser on the same network. Sign in as rokudev, select the downloaded ZIP, and install it.

03 / PLAY

Add your playlist

Open the app’s playlist settings and enter an HTTP(S) M3U URL reachable from Roku. Or start with the bundled demo. Your playlist address and favorites stay in the app registry.

Built for Roku, released independently.

Why a separate repository?

Roku uses its own runtime, UI, packaging and signing process. Keeping it in ottplay-roku lets the client ship independently from the web player. Shared profile and controller support will use versioned contracts, with explicit compatibility tests.

Why BrightScript rather than the new TypeScript SDK?

The current RSG 2.0 SDK beta supports sideload only. BrightScript and SceneGraph let the same app move from sideload to a signed Beta package. The new SDK can be evaluated later without blocking this delivery path. Roku SDK status.

Will every video work?

Playback depends on your Roku model, native codecs and source. The app passes supported HTTP(S) streams to Roku Video. Browser-only engines, custom HTTP headers, DRM and unsupported codecs are not converted by this client. A media server may be needed for compatible output.

Where are my files and playlist credentials?

The website does not receive your playlist. The app reads the URL you enter and plays its media directly. The source URL and favorites are saved in the device registry; use HTTPS for private sources. Remove personal data before sharing a device or any custom package.
